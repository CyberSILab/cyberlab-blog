## 模型简介

LFM3-1.7B 主打工具调用和 Agent 场景：体积小、响应快，原生支持 256K 上下文，适合做本地自动化流程里的小脑。

## 硬件与下载

- Q4_K_M 量化约 1.2GB，几乎任何机器都能跑
- 256K 上下文需要约 16GB 内存，按需开启

## 部署步骤

    ollama pull lfm3-1.7b
    ollama run lfm3-1.7b

接 Agent 框架时直接开启 function-calling 模板，对常见工具（搜索、计算器、文件读写）识别很稳。

## 实测效果

- 工具调用正确率约 92%，小模型里非常突出
- 256K 长文检索会漏中间信息，128K 以内更可靠
- CPU 上单句响应 < 0.5 秒，做流程节点很合适

## 小结

做本地 Agent 流程的轻量首选。复杂推理任务请换更大的模型，它更适合当"调度小脑"。
